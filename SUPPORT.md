# Support & Community Help

Welcome to the OBLIQ-in community! Whether you are a developer contributing code, a Chartered Accountant (CA) testing the workspace, or an article assistant providing feedback, here is how you can find help and get in touch with the team.

## Getting Help

### 1. GitHub Discussions (Questions, Ideas & Architecture)

For general questions, design ideas, or architecture discussions:

- Join our [GitHub Discussions](https://github.com/OBLIQ-in/obliq-in-app/discussions).
- Search existing topics before posting new questions.
- Share feedback on CA workflow usability, tax compliance concepts, or UI layout.

### 2. GitHub Issues (Bug Reports & Planned Features)

If you encounter a reproducible bug or wish to work on an existing task:

- Search existing [GitHub Issues](https://github.com/OBLIQ-in/obliq-in-app/issues) to verify if the issue has already been reported.
- If not found, open a new issue using our structured issue templates (`bug_report.md` or `feature_request.md`).
- For contribution workflows, see [CONTRIBUTING.md](CONTRIBUTING.md).

### 3. Security Concerns

- For security vulnerabilities, **do not open a public issue**.
- Follow our [Security Policy](SECURITY.md) to report issues confidentially via [GitHub Security Advisories](https://github.com/OBLIQ-in/obliq-in-app/security/advisories/new) or by emailing **security@obliq.in**.

### 4. Chartered Accountant (CA) Domain Review

- If you are a practising CA, tax consultant, or audit professional reviewing compliance logic (e.g., GSTIN validation, ITC reconciliation, GSTR returns, or audit trial trails), tag your issues or PRs with `needs-ca-review`.

## Community Standards

Please remember that all interactions within the OBLIQ-in community are governed by our [Code of Conduct](CODE_OF_CONDUCT.md). Please treat all members with respect and professionalism.
